# **Lost Trail**

An upcoming ASCII-style adventure game set in a fantasy world. A project created to:

 - Learn the Tkinter library
 - Go through the full indie game development cycle


---
# Game Specifications:


**Genre**: Quest, adventure

**Setting**: Fantasy

**Graphics**: ASCII characters

**Sound/Music**: Folk, minimalist, medieval

**Platforms**: Windows, Linux (tentatively macOS)

**View**: 2D, ASCII-based visuals

**Combat format**: JRPG / Top-down

---
# Technologies and Libraries (In development)
Libraries: Tkinter

Language: Python


---
# Installation (In development)

1. Run the following command in the terminal:
   git clone https://github.com/agrikol2/Lost-Trail.git

2. Navigate to the project folder: `cd Lost_Trail`

3. Manually open the folder in VS Code: File -> Open Folder -> Lost-Trail

4. Open the `main.py` file and run it by pressing F5

	**Project Functionality (In development)**

	1 - The "Quit" button closes the application
	
	2 - The "Credits," "Settings," and "New Game" buttons open a new frame while hiding the old one (work in progress)
